# vector
Копия std::vector

## Описание
Тренировочный проект — собственная реализация динамического массива (`std::vector`) на C++.

Реализован полноценный шаблонный класс `Vector<T>` с сырым управлением памятью через `RawMemory<T>`, поддержкой итераторов, вставки (`Insert`, `Emplace`), удаления (`Erase`, `PopBack`), реаллокации с гарантиями безопасности исключений и move-семантикой. Для тестирования используется набор assert-тестов, которые проверяют корректность при различных сценариях (конструирование, копирование, перемещение, вставка с расширением, обработка ошибок и т.д.).
